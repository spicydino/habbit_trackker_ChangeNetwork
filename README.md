# habbit_tracker

A Simple and elegant flutter app to track your daily habits and visualize your progress. Designed for Quick use and clear feedback.

## Setup Instructions

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) (v3.10+ recomended)
- Dart SDK (included with Flutter)
- Android studio or Visual studio code
- Physical device or  Emulator

## Instalation Steps

### Step 1: Clone the project

``` cmd
git clone https://github.com/spicydino/habbit_trackker_ChangeNetwork.git
```

### Step 2: To Run

``` cmd
flutter pub get
flutter run
```

## Key Features Implemented

- Add Habit: Create and manage custom daily habits.
- Progress Indicator Widget: Shows percentage completed using a beautiful progress bar.
- Daily Tracking UI: Tap to mark each habit as done for the day.
- Summary Display: Shows total habits completed out of total assigned.
- Constants File: Centralized app colors and styling for easy updates.
